# ZoeAdmin - ប្រព័ន្ធគ្រប់គ្រងអីវ៉ាន់ (Admin)

**ZoeAdmin** គឺជាកម្មវិធីគេហទំព័រ (Web App) សម្រាប់បុគ្គលិកគ្រប់គ្រង (Admin) ប្រើសម្រាប់បញ្ចូល និងគ្រប់គ្រងទិន្នន័យកញ្ចប់ទំនិញ (Parcel/Package) របស់អតិថិជនទាំងអស់ ចាប់ពីការស្កេន Barcode បញ្ចូលកញ្ចប់ថ្មី រហូតដល់ការគណនាប្រាក់ត្រូវទារ (COD/DOD) និងស្ថិតិចំណូល។ កម្មវិធីនេះជា **App គ្រប់គ្រងសំខាន់ (Main Admin)** នៃប្រព័ន្ធ ដែល **ZoeW** (កម្មវិធីទទួល/តាមដានកញ្ចប់) និង **Zscan** (កម្មវិធីកំណត់ទីតាំង Locker) ទាំងពីរ អានទិន្នន័យរួមគ្នាតាមរយៈ Firebase Database ដូចគ្នា។

កម្មវិធីនេះជា **PWA (Progressive Web App)** អាចដំឡើងលើទូរស័ព្ទ ឬកុំព្យូទ័របាន ហើយប្រើ **Firebase** (Authentication + Realtime Database) ជា Backend សម្រាប់ការចូលប្រើប្រាស់ និងផ្ទុកទិន្នន័យ។

## លក្ខណៈពិសេស (Features)

- 🔐 **ការចូលប្រើប្រាស់សុវត្ថិភាព** — ចូលប្រើប្រាស់តាមរយៈ Firebase Authentication (Email/Password), កូដ PIN សុវត្ថិភាពសម្រាប់ការកំណត់រចនាសម្ព័ន្ធ, និងប្រព័ន្ធការពារការបើក Developer Tools
- 📷 **ស្កេន Barcode** — ស្កេនតាមកាមេរ៉ា (Camera), ម៉ាស៊ីនស្កេន Bluetooth/USB, ឬវាយបញ្ចូលដោយដៃ
- 📦 **បញ្ចូល/គ្រប់គ្រងកញ្ចប់** — កត់ត្រាកញ្ចប់ថ្មីតាមលេខទូរស័ព្ទអតិថិជន, កូដ Barcode ច្រើនក្នុងកញ្ចប់តែមួយ, និងកែប្រែព័ត៌មានអតិថិជន
- 💰 **គណនាប្រាក់ COD/DOD** — គណនាទឹកប្រាក់ត្រូវទារជា USD ($) និង Riel (៛) ដោយស្វ័យប្រវត្តិ តាមអត្រាប្តូរប្រាក់ដែលកំណត់បាន
- ⚙️ **កែប្រែស្ថិតិដោយដៃ** — កែប្រែ COD, DOD និងចំនួនកញ្ចប់ដោយដៃ សម្រាប់ថ្ងៃជាក់លាក់ណាមួយ
- 🏷️ **កែប្រែតម្លៃ Barcode** — កែប្រែ ឬលុប Barcode នីមួយៗក្នុងកញ្ចប់
- 📊 **ស្ថិតិចំណូល** — របាយការណ៍ចំណូលប្រចាំថ្ងៃ និងប្រចាំខែ (COD & DOD ៣ ខែចុងក្រោយ)
- 🔍 **ស្វែងរក & Lookup API** — ស្វែងរកកញ្ចប់តាមលេខទូរស័ព្ទ ព្រមទាំងភ្ជាប់ API ខាងក្រៅសម្រាប់ស្វែងរកព័ត៌មានអតិថិជនស្វ័យប្រវត្តិ
- 🗑️ **គ្រប់គ្រងការលុប** — លុបកញ្ចប់តែមួយ ឬលុបទាំងអស់, ស្តារទិន្នន័យពី "ទិន្នន័យលុបបណ្តោះអាសន្ន" មកវិញបាន, និងច្បាប់លុបស្វ័យប្រវត្តិបន្ទាប់ពីរយៈពេលកំណត់
- 📱 **ដំឡើងជា App បាន (PWA)** — គាំទ្រ Service Worker សម្រាប់ប្រើប្រាស់ក្រៅបណ្តាញ (Offline)

## សុវត្ថិភាព (Security)

- ការចូលប្រើប្រាស់តម្រូវឲ្យមានគណនី Firebase Authentication
- មានកូដ PIN ដាច់ដោយឡែកសម្រាប់ការកែប្រែការកំណត់រចនាសម្ព័ន្ធ (Config)
- មានប្រព័ន្ធការពារការបើក Developer Tools ដើម្បីការពារទិន្នន័យ
- ទិន្នន័យទាំងអស់ដែលមកពី Firebase (លេខទូរស័ព្ទ, Barcode, ព័ត៌មានអតិថិជន) ត្រូវបាន Escape មុននឹងបង្ហាញ ដើម្បីការពារការវាយប្រហារ XSS
