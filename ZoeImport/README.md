# ZoeImport — PWA នាំចូល Excel ចូល Google Sheet

PWA ដាច់ដោយឡែក (ដំឡើងលើទូរស័ព្ទបានដូច ZoeW និង ZoeKeyGen) សម្រាប់នាំចូល
ឯកសារ Excel ដែល export ចេញពី website ZTO ចូលទៅ Google Sheet `Customers` —
ជំនួសការ copy-paste ដោយដៃ។

> **វាមិនប៉ះ ZoeW ឬ ZoeKeyGen ឡើយ។** វាជា site ដាច់ដោយឡែក ដែលនិយាយតែជាមួយ
> Apps Script ក្នុង [`../zto-import/`](../zto-import/README.md) ប៉ុណ្ណោះ។
> **វាមិនចេះនិយាយជាមួយ Firebase ទេ។**

កំណែបច្ចុប្បន្ន **`1.3.2`** (ដាច់ដោយឡែកពី `APP_VERSION` របស់ ZoeW/ZoeKeyGen)។

របាខាងលើមាន **សូចនាករតំណ** ដែលប្តូរ realtime តាមអ្វីដែលកើតឡើងពិត៖
«មិនទាន់ភ្ជាប់» · «កំពុងទាក់ទង Sheet...» · «ភ្ជាប់ Sheet រួចរាល់» ·
«ភ្ជាប់ Sheet មិនបាន» · «ក្រៅបណ្ដាញ»។ ពេលឧបករណ៍ក្រៅបណ្ដាញ សំណើត្រូវបដិសេធ
**មុនចេញដំណើរ** ជាមួយសារច្បាស់លាស់ ជំនួសការរង់ចាំអស់ពេល ៣០ វិនាទី។
កំណែបង្ហាញនៅរបាខាងលើ ក្រោម Credit tag «Powered By ZoeW»។

## ជំហានរៀបចំលើកដំបូង

### ១. រៀបចំ Apps Script ជាមុនសិន

ធ្វើតាម [`../zto-import/README.md`](../zto-import/README.md) ជំហានទី ១–៣។
ចុងបញ្ចប់អ្នកនឹងមានរបស់ ២៖

- **Web app URL** ដែលមានទម្រង់ `https://script.google.com/macros/s/…/exec`
- **`IMPORT_PASSWORD`** ដែលអ្នកកំណត់ក្នុង ScriptProperties

> ⚠️ URL ត្រូវតែជា `…/exec` **មិនមែន `…/dev` ទេ**។ `/dev` ដើរតែពេលអ្នក
> ចូលគណនី Google ក្នុង browser នោះ ➜ វាបរាជ័យលើទូរស័ព្ទ។

### ២. Deploy ថតនេះជា Netlify site ដាច់ដោយឡែក

Netlify ➜ **Add new site** ➜ ភ្ជាប់ repo នេះ ➜ **Base directory: `ZoeImport`**។

- គ្មាន build command ទេ (static site)។
- `netlify.toml` ក្នុងថតនេះកំណត់ header សុវត្ថិភាព និង CSP រួចជាស្រេច។
- ត្រូវប្រើ **HTTPS** ជានិច្ច បើអត់ការអ៊ិនគ្រីប និង PIN ដំណើរការមិនកើត
  (App ប្រាប់ដោយផ្ទាល់បើវាមិនស្ថិតក្នុង secure context)។

### ៣. កំណត់ PIN

បើក URL របស់ site ➜ អេក្រង់ដំបូងសុំ **កំណត់លេខកូដសុវត្ថិភាព**៖

1. វាយ PIN **យ៉ាងតិច ៤ ខ្ទង់** ក្នុងប្រអប់ទី ១
2. វាយម្តងទៀតឲ្យត្រូវគ្នាក្នុងប្រអប់ទី ២
3. ចុច **រក្សាទុក PIN**

> PIN នេះជា **កូនសោអ៊ិនគ្រីប** មិនមែនត្រឹមតែ gate ទេ។ បើភ្លេច ➜ ស្រាយការ
> តភ្ជាប់មិនបាន ➜ ត្រូវកំណត់ URL និងពាក្យសម្ងាត់ឡើងវិញ។ ទិន្នន័យក្នុង
> Google Sheet មិនរងផលទេ។

### ៤. កំណត់ការតភ្ជាប់

ក្នុងកាត **១ · ការតភ្ជាប់**៖

1. បំពេញ **Web app URL របស់ Apps Script**
2. បំពេញ **ពាក្យសម្ងាត់នាំចូល (IMPORT_PASSWORD)**
3. ចុច **សាកល្បង និងរក្សាទុក**

App នឹងផ្ញើសំណើពិតមួយទៅ Apps Script មុននឹងរក្សាទុក ➜ បើពាក្យសម្ងាត់ខុស
ឬ URL មិនត្រឹមត្រូវ វាប្រាប់ភ្លាម ហើយ **មិនរក្សាទុកអ្វីទាល់តែសោះ**។

### ៥. ដំឡើងជា App លើទូរស័ព្ទ

- **iPhone/iPad** ➜ Safari ➜ ប៊ូតុង Share ➜ **Add to Home Screen**
- **Android** ➜ Chrome ➜ ម៉ឺនុយ ⋮ ➜ **Install app**

មិនចូល cache របស់ Service Worker ➜ មុខងារស្លាប់ស្ងាត់ៗពេលបណ្តាញខ្សោយ។

App នេះ **គ្មានធនធានឆ្លង origin ក្នុង `<head>` សោះ** ➜ វាមិនអាចជាប់អេក្រង់ស
ដោយសារ CDN ខាងក្រៅមិនឆ្លើយបានទេ។

### ស្រទាប់ការពារ

| អ្វី | របៀបការពារ |

| **វាយ PIN ខុស** | ៥ ដង ➜ ចាក់សោ ១ នាទី |
| **ចាក់សោ (🔒)** | លុបកូនសោក្នុងសតិ · URL · ពាក្យសម្ងាត់ · preview និងវាល form ចេញពី DOM |

| **សំណើមានពេលកំណត់ពិត** | ៣០ វិនាទី ជាមួយ `AbortController` ➜ មិនព្យួររហូតលើបណ្តាញ «ភ្ជាប់តែស្លាប់» |
