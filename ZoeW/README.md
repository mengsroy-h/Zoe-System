## កំណែ

- បង្ហាញ **២ កន្លែង** ៖ ប្រអប់ចូលប្រព័ន្ធ និងខាងក្រោមរបា Slide។

  រាល់ពេលឯកសារ static ណាមួយប្រែ។ កំណែថ្មីមកដល់តាមផ្លូវនោះ — ពេល Service
  Worker ថ្មីចាប់យក របាជូនដំណឹងលេចឡើងឲ្យអ្នកប្រើ Refresh។
- ប្រវត្តិការផ្លាស់ប្តូរពេញលេញ ៖ **[CHANGELOG.md](../CHANGELOG.md)**។

### ការស្កេន និងការបញ្ចូល

- **ផ្លូវស្កេន ៣** — កាមេរ៉ា · ម៉ាស៊ីនស្កេន hardware · រូបភាពក្នុងឧបករណ៍។
  គ្រប់ផ្លូវឆ្លងកាត់ចំណុចបំបែកតែមួយ ដូច្នេះឥរិយាបថដូចគ្នាបេះបិទ។
- **Engine ZXing C++ ចងក្រងជា WebAssembly** ស្ថិតក្នុង repo។ លើ Android វាប្រើ
  `BarcodeDetector` ដើមរបស់ប្រព័ន្ធពេលមាន។
- **ទទួលតែ CODE-128** — format ដែលមានលេខផ្ទៀងផ្ទាត់ជាកាតព្វកិច្ច។
- **ការបញ្ជាក់ ២ ស៊ុមជាប់គ្នា** លើផ្លូវកាមេរ៉ា ជាជាន់ការពារទី ២។
- **ជួរអានសម្របតាមឧបករណ៍** និង **ការទប់ស្កាត់ Barcode ស្ទួន ៥ ជាន់**។
- **របៀបស្កេន ២** — កញ្ចប់ និងទីតាំង Locker។

### ទិន្នន័យ និងចំណូល

- **COD និង DOD** ក្នុងកញ្ចប់តែមួយ បូកលេខទូរស័ព្ទ និងទីតាំង Locker។
- **Barcode ច្រើនក្នុងកញ្ចប់តែមួយ** — កែ ឬដកចេញម្តងមួយបាន។
- **ស្ថិតិប្រចាំថ្ងៃ និងប្រចាំខែ** ៖ **អតិថិជនយក** = លេខទូរស័ព្ទផ្សេងៗគ្នាដែល
  មាន barcode បិទ >= ១ · **កញ្ចប់យក** = ចំនួន barcode បិទ។
- **អត្រាប្តូរប្រាក់រៀល** ចែករំលែករវាងឧបករណ៍ទាំងអស់។
- **តម្រងតាមថ្ងៃ** និងស្វែងរកតាមកន្ទុយលេខទូរស័ព្ទ ៣–៤ ខ្ទង់។
- **ធុងសំរាម និងការស្តារ**។
- **ថ្ងៃ និងម៉ោងគិតតាម `Asia/Phnom_Penh` គ្រប់ឧបករណ៍** — ឧបករណ៍ដែលកំណត់
  តំបន់ម៉ោងផ្សេង ក៏ចុះចំណូលចូលថ្ងៃដដែល។

## របៀបប្រើប្រាស់

### ១. Deploy

Netlify site មួយ ដោយ **Base directory = `ZoeW`** · Build command **ទទេ** ·
Publish directory **`.`**។ គ្មាន build step ទេ។

Firebase rules (`../firebase-database.rules.json`) ត្រូវ paste ចូល Firebase
Console ➜ **Publish** ដោយដៃ។ ⛔ វាមិន deploy ស្វ័យប្រវត្តិទេ។

### ២. ដំឡើងឧបករណ៍ថ្មី

1. បើក URL ➜ paste **Activation Key** (ត្រូវការអ៊ីនធឺណិត)។
2. បញ្ចូល **Firebase Config** ៖ ⚙️ របា Slide ➜ Config — ឬបើក **Setup Link/QR**
   ដែលចេញពី ZoeKeyGen (នៅតែសុំ PIN មុនរក្សាទុក)។
3. **ចូលប្រព័ន្ធ** ដោយអ៊ីមែល/ពាក្យសម្ងាត់ Firebase។
4. កំណត់ **Security PIN** ➜ ⚙️ របា Slide។
5. (ស្រេចចិត្ត) បើក **ក្រយៅដៃ/មុខ** និងដំឡើងជា PWA។

- **`script-src` គ្មាន `'unsafe-inline'`** ➜ អក្សរចម្លែកដែលចូលដល់ទំព័រ
  មិនអាចរត់បានទេ។ ការចុចប៊ូតុងធ្វើតាម `data-act` បូក **បញ្ជីអនុញ្ញាត**។
- **គ្មាន `onclick=` សល់សោះ** ➜ ថ្នាក់កំហុស «escape ២ ជាន់» កើតមិនបាន។
- **`frame-ancestors 'none'`** · **`object-src 'none'`** · **`base-uri 'self'`** ·
  HSTS · `X-Content-Type-Options: nosniff`។
- **Service Worker បោះបង់សំណើឆ្លង origin** ➜ គ្មានធនធានខាងក្រៅចូល cache។

### Firebase Rules

- Root **default-deny**; គ្រប់ node តម្រូវ `auth != null`។
- **Schema validation** — ប្រភេទវាល ជួរតម្លៃ និង `$other: false`។
- **Claim/witness fence** លើការស្តារ និងការលុបទាំងអស់ ➜ replay និងការគិតលុយ
  ស្ទួនកើតមិនបាន។
- ⛔ Rules **មិន deploy ស្វ័យប្រវត្តិទេ** — paste ចូល Console ➜ Publish។

### ព្រំដែនដែលត្រូវដឹង

- **គ្មានតួនាទី** ក្នុង App នេះ — អ្នកប្រើដែលចូលបានមានសិទ្ធិដូចគ្នា។
- ព្រោះគ្មាន backend ដែលទុកចិត្តបាន **អ្នកប្រើអាចសរសេរតួលេខចំណូលដោយផ្ទាល់**
  ហើយ **គ្មានការផ្ទៀងផ្ទាត់ aggregate**។
- **Firebase Config មិនមែនជាសម្ងាត់ទេ** តាមការរចនា — Rules ទើបជាការការពារពិត។
- កុំទុក PIN, Config, API secret ឬឯកសារ export លើឧបករណ៍សាធារណៈ។
