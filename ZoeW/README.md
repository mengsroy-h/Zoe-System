# ZoeW - ប្រព័ន្ធគ្រប់គ្រងអីវ៉ាន់

**ZoeW** គឺជាកម្មវិធីគេហទំព័រ (Web App) សម្រាប់តាមដាន និងគ្រប់គ្រងកញ្ចប់ទំនិញ (Parcel/Package) របស់អតិថិជន ដែលមកទទួលនៅចំណតឬហាងទទួលកញ្ចប់ (Pickup Point / Locker) ។ កម្មវិធីនេះជួយតាមដានកញ្ចប់ដែលចូល តាមដានប្រាក់ត្រូវទារពីអតិថិជន (COD/DOD) និងផ្តល់ស្ថិតិចំណូលប្រចាំថ្ងៃ/ប្រចាំខែ។

កម្មវិធីនេះជា **App សម្រាប់ការទទួល/តាមដានកញ្ចប់** ក្នុងប្រព័ន្ធតែមួយជាមួយ **ZoeAdmin** (App គ្រប់គ្រងសំខាន់ ដែលបញ្ចូលទិន្នន័យកញ្ចប់ថ្មី) និង **Zscan** (App កំណត់ទីតាំង Locker) ដោយអានទិន្នន័យរួមគ្នាតាមរយៈ Firebase Database ដូចគ្នា។ ខុសពី ZoeAdmin, **ZoeW មានសិទ្ធិប្រើប្រាស់តែមុខងាររបស់ខ្លួនប៉ុណ្ណោះ** — ដូចជាហៅទូរស័ព្ទ, បិទ/បើកបញ្ជី, កែលេខទូរស័ព្ទ, មើលស្ថិតិ — មិនមានមុខងារបញ្ចូល/ស្កេនកញ្ចប់ថ្មីទេដូច ZoeAdmin ទេ។

កម្មវិធីនេះជា **PWA (Progressive Web App)** អាចដំឡើងលើទូរស័ព្ទ ឬកុំព្យូទ័របាន ហើយប្រើ **Firebase** (Authentication + Realtime Database) ជា Backend សម្រាប់ការចូលប្រើប្រាស់ និងផ្ទុកទិន្នន័យ។

## លក្ខណៈពិសេស (Features)

- 🔐 **ការចូលប្រើប្រាស់សុវត្ថិភាព** — ចូលប្រើប្រាស់តាមរយៈ Firebase Authentication (Email/Password) និងកូដ PIN សុវត្ថិភាពសម្រាប់កំណត់រចនាសម្ព័ន្ធ
- 📦 **គ្រប់គ្រងកញ្ចប់ប្រចាំថ្ងៃ** — កត់ត្រាកញ្ចប់តាមលេខទូរស័ព្ទអតិថិជន, កូដបារកូដ (Barcode), និងទីតាំងទុក (Locker)
- 💰 **តាមដានប្រាក់ COD/DOD** — គណនាទឹកប្រាក់ត្រូវទារជា USD ($) និង Riel (៛) ដោយស្វ័យប្រវត្តិ
- 📅 **តម្រងតាមកាលបរិច្ឆេទ** — មើលទិន្នន័យថ្ងៃនេះ ម្សិលមិញ ម្សិលម្ងៃ ឬជ្រើសរើសកាលបរិច្ឆេទផ្សេងទៀត
- 📊 **ស្ថិតិចំណូល** — របាយការណ៍ចំណូលប្រចាំថ្ងៃ និងប្រចាំខែ
- 🔍 **ស្វែងរកលេខទូរស័ព្ទ** — ស្វែងរកកញ្ចប់របស់អតិថិជនយ៉ាងរហ័សតាមលេខទូរស័ព្ទ
- 📞 **ការហៅទូរស័ព្ទ** — ចុចហៅទូរស័ព្ទទៅអតិថិជនផ្ទាល់ពីកម្មវិធី ព្រមទាំងសម្គាល់ស្ថានភាព "បានហៅ"
- ✅ **ស្ថានភាពកញ្ចប់** — កំណត់ថាកញ្ចប់ត្រូវបានបិទ (អតិថិជនបានយក) ឬនៅសល់
- 🗑️ **ធុងសំរាម (Recently Deleted)** — ស្តារទិន្នន័យដែលបានលុបមកវិញបាន
- 📱 **ដំឡើងជា App បាន (PWA)** — គាំទ្រ Service Worker សម្រាប់ប្រើប្រាស់ក្រៅបណ្តាញ (Offline)

## សុវត្ថិភាព (Security)

- ការចូលប្រើប្រាស់តម្រូវឲ្យមានគណនី Firebase Authentication
- មានកូដ PIN ដាច់ដោយឡែកសម្រាប់ការកែប្រែការកំណត់រចនាសម្ព័ន្ធ (Config)
- មានប្រព័ន្ធការពារការបើក Developer Tools ដើម្បីការពារទិន្នន័យ

### ចំណុចខ្វះខាតដែលទទួលស្គាល់ (Known Accepted Risks)

គណនី Worker (ដែលបានចូល ZoeW) មានសិទ្ធិសរសេរ `cod`/`dod`/`price`/`count`/`barcode` និងស្ថិតិចំណូលប្រចាំថ្ងៃ/ខែបានដោយផ្ទាល់តាម Firebase API ជាង UI ZoeW ផ្តល់ឲ្យ (Insider-risk តែប៉ុណ្ណោះ — ត្រូវការគណនី Worker ត្រឹមត្រូវជាមុនសិន)។ សូមមើលព័ត៌មានលម្អិតក្នុង [ZoeAdmin/README.md](../ZoeAdmin/README.md#ចំណុចខ្វះខាតដែលទទួលស្គាល់-known-accepted-risks)។ ការបិទបញ្ហានេះឱ្យជិតស្និទ្ធពិតត្រូវការ Firebase Cloud Functions ដែលមិនទាន់បាន Deploy។
