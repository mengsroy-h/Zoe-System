១. ស្គាល់ ZoeW

ZoeW ជា PWA សម្រាប់គ្រប់គ្រងកញ្ចប់អីវ៉ាន់ អតិថិជន ទីតាំង Locker ទឹកប្រាក់ និងស្ថិតិអាជីវកម្ម។ ទិន្នន័យសំខាន់រក្សាទុកក្នុង Firebase Realtime Database ហើយ App អាចដំឡើងលើ Android, iPhone, tablet និង desktop។

ប្រភពលេខកំណែ៖ លេខកំណែដែលបង្ហាញក្នុងប្រអប់ Login និងខាងក្រោមរបា Slide ជាលេខពិតរបស់ ZoeW។ ចុចលើលេខនោះដើម្បីបើកសៀវភៅនេះ។

ពាក្យសំខាន់

  • កញ្ចប់ អាចមាន Barcode មួយ ឬច្រើន ហើយភ្ជាប់លេខទូរស័ព្ទតែមួយ។
  • COD និង DOD ជាទឹកប្រាក់ពីរប្រភេទដែល App កត់ត្រាដាច់ដោយឡែក។
  • យករួច មានន័យថា Barcode ត្រូវបានបិទដោយសារអតិថិជនមកយក។
  • មិនទាន់យក ជា Barcode ដែលនៅរង់ចាំ និងមិនទាន់ត្រូវរាប់ជាចំណូល។

២. ចាប់ផ្ដើម និងដំឡើង

  1. បើក URL ផ្លូវការ
    ប្រើ Chrome, Edge ឬ Safari កំណែថ្មី។ កុំប្រើ URL ដែលផ្ញើពីប្រភពមិនស្គាល់។
  2. ដាក់ Activation Key
    ការផ្ទៀងផ្ទាត់លើកដំបូងត្រូវការអ៊ីនធឺណិត។
  3. កំណត់ Firebase និងចូលប្រព័ន្ធ
    ប្រើ Setup Link/QR ឬបញ្ចូល Config ដោយដៃ រួចចូលដោយគណនី Firebase។
  4. កំណត់ Security PIN
    PIN ការពារសកម្មភាពសំខាន់ និងអ៊ិនគ្រីបការកំណត់រសើបលើឧបករណ៍។
  5. ដំឡើងជា PWA
    Android/Chrome៖ ម៉ឺនុយ browser → Install app។ iPhone/Safari៖ Share → Add to Home Screen។
កុំលុប browser data ដោយមិនចាំបាច់។ វាអាចលុប Activation, PIN, cache Offline និងការកំណត់ដែលរក្សាទុកលើឧបករណ៍។ ទិន្នន័យក្នុង Firebase មិនត្រូវលុបតាមទេ។

៣. Activation និង Firebase

Setup Link/QR

  1. ទទួល Setup Link ឬ QR ពី ZoeKeyGen ដែលទុកចិត្តបាន។
  2. នៅ ZoeW ចូលរបា Slide → កំណត់ត្រាសម្ងាត់ Firebase → ស្កេន QR ឬបើក link។
  3. ផ្ទៀងផ្ទាត់ Security PIN មុនរក្សាទុក។
  4. ចុច រក្សាទុក និងភ្ជាប់ ហើយរង់ចាំស្ថានភាព Firebase បង្ហាញថាភ្ជាប់រួច។

បញ្ចូល Firebase Config ដោយដៃ

ចម្លង object config ពី Firebase Console → Project settings → Your apps។ វាត្រូវមានវាលដូចជា apiKey, authDomain, databaseURL, projectId និង appId។

សុវត្ថិភាព៖ Firebase Config មិនមែនជាពាក្យសម្ងាត់ ប៉ុន្តែ Database Rules និង Authentication ត្រូវតែកំណត់ត្រឹមត្រូវ។ កុំផ្ញើ PIN, ពាក្យសម្ងាត់ ឬ API secret ក្នុង chat ឬ screenshot។

៦. ការស្កេនកញ្ចប់

ជ្រើសរបៀបស្កេន ៣

  • បញ្ចូលកញ្ចប់៖ សម្រាប់កញ្ចប់ថ្មី។
  • កំណត់ទីតាំង Locker៖ សម្រាប់ផ្លាស់ទីតាំង Barcode ដែលមានស្រាប់។
  • ស្កេនដកកញ្ចប់៖ សម្រាប់ដក Barcode ពិតចេញ និងកាត់ស្ថិតិម្តងគត់។

ផ្លូវបញ្ចូល ៤

  • កាមេរ៉ា៖ អនុញ្ញាតសិទ្ធិកាមេរ៉ា រក្សា Barcode ឲ្យនៅក្នុងស៊ុម ហើយរង់ចាំការបញ្ជាក់ពីរស៊ុម។
  • Hardware scanner៖ ដាក់ cursor ក្នុងប្រអប់ រួចស្កេនឲ្យឧបករណ៍បញ្ចូន Enter។
  • រូបភាព៖ ជ្រើសរូបច្បាស់ដែលមាន Barcode CODE-128 មួយ។
  • វាយដោយដៃ៖ វាយ Barcode ពេញ រួចចុច បញ្ជូន។

បំពេញទិន្នន័យក្រោយស្កេន

  1. ពិនិត្យ Barcode និងស្ថានភាព Lookup។
  2. បំពេញ ឬផ្ទៀងផ្ទាត់លេខទូរស័ព្ទ។
  3. ពិនិត្យទីតាំង Locker និងទឹកប្រាក់ COD/DOD។
  4. ចុច យល់ព្រម ដើម្បីរក្សាទុក។ ប្រសិនបើ Lookup រកមិនឃើញ ហើយអ្នកពិតជាចង់បន្តដោយគ្មានទិន្នន័យនោះ ចុច រំលង។

ដកកញ្ចប់ដោយស្កេន Barcode

  2. ស្កេន Barcode តាមផ្លូវណាមួយក្នុងចំណោមផ្លូវ ៤ ខាងលើ។
  3. ផ្ទៀងផ្ទាត់ Barcode, លេខទូរស័ព្ទ, Locker, COD, DOD និងស្ថានភាពក្នុងផ្ទាំងបញ្ជាក់។
