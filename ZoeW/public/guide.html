១. ស្គាល់ ZoeW

ប្រភពលេខកំណែ៖ លេខកំណែដែលបង្ហាញក្នុងប្រអប់ Login និងខាងក្រោមរបា Slide ជាលេខពិតរបស់ ZoeW។ ចុចលើលេខនោះដើម្បីបើកសៀវភៅនេះ។

២. ចាប់ផ្ដើម និងដំឡើង

  1. បើក URL ផ្លូវការ
    ប្រើ Chrome, Edge ឬ Safari កំណែថ្មី។ កុំប្រើ URL ដែលផ្ញើពីប្រភពមិនស្គាល់។
  2. ដាក់ Activation Key
    ការផ្ទៀងផ្ទាត់លើកដំបូងត្រូវការអ៊ីនធឺណិត។ ហាងដែលចូលប្រើដោយ កូដអញ្ជើញ ➜ មើលផ្នែក ៣ខ។
  3. កំណត់ Firebase និងចូលប្រព័ន្ធ
    ប្រើ Setup Link/QR ឬបញ្ចូល Config ដោយដៃ រួចចូលដោយគណនី Firebase។
  4. កំណត់ Security PIN
    PIN ការពារសកម្មភាពសំខាន់ និងអ៊ិនគ្រីបការកំណត់រសើបលើឧបករណ៍។
  5. ដំឡើងជា PWA
    Android/Chrome៖ ម៉ឺនុយ browser → Install app។ iPhone/Safari៖ Share → Add to Home Screen។ ឬប្រើ App Android ដែលអ្នកលក់ផ្ញើជាឯកសារ APK។
កុំលុប browser data ដោយមិនចាំបាច់។ វាអាចលុប Activation, PIN, cache Offline និងការកំណត់ដែលរក្សាទុកលើឧបករណ៍។ ទិន្នន័យក្នុង Firebase មិនត្រូវលុបតាមទេ។

៣. Activation និង Firebase

ចំនួនឧបករណ៍ក្នុង Activation Key ១

Activation Key ១ ប្រើបានតាម ចំនួនឧបករណ៍ដែលអ្នកលក់កំណត់ (លំនាំដើម ១ ឧបករណ៍ អតិបរមា ៥)។ ឧបករណ៍នីមួយៗកក់កៅអី ១ នៅពេល Activate ដំបូង ហើយកៅអីនោះនៅជាប់នឹងឧបករណ៍នោះ។

  • ឧបករណ៍ដដែល Activate ម្ដងទៀត មិនស៊ីកៅអីថ្មី។
  • សារ «Key នេះប្រើគ្រប់ចំនួនឧបករណ៍ដែលអនុញ្ញាតហើយ!» មានន័យថាកៅអីអស់ ➜ សុំអ្នកលក់ចុច 📱 ចំនួនឧបករណ៍ ដើម្បីបន្ថែម ឬ 🔓 ដោះឧបករណ៍ ដើម្បីដោះឧបករណ៍ចាស់ចេញ។
  • ប្ដូរទូរស័ព្ទ ឬលុប browser data ➜ ឧបករណ៍ក្លាយជាឧបករណ៍ថ្មី ➜ ត្រូវការកៅអីទំនេរ។ សុំ 🔓 ដោះឧបករណ៍ ជាមុន។
  • សារ «សម្គាល់ឧបករណ៍នេះមិនបានទេ!» មានន័យថា Storage របស់ Browser ត្រូវបានបិទ ➜ បើក Cookie/Storage រួចសាកម្ដងទៀត។
iPhone ៖ App ដែលដំឡើងលើអេក្រង់ដើម និង Safari ធម្មតា ប្រើ Storage ដាច់ពីគ្នា ➜ ពួកវារាប់ជាឧបករណ៍ ២ ផ្សេងគ្នា។ សូម ដំឡើងជា PWA មុន រួចទើប Activate។

Setup Link/QR

  1. ទទួល Setup Link ឬ QR ពី ZoeKeyGen ដែលទុកចិត្តបាន។ មិនទាន់មានគណនី ឬ Setup Link ➜ ចុចតំណ @mengsroyhun ក្នុងប្រអប់ ⚙️ ភ្ជាប់ប្រព័ន្ធ ដើម្បីទាក់ទងបង្កើតគណនីតាម Telegram។
  2. បើក link នោះ ឬនៅ ZoeW ចូលរបា Slide → Config / Reconfig → ប្រអប់ ⚙️ ភ្ជាប់ប្រព័ន្ធ ហើយជ្រើសមួយ ៖ 📷 ស្កេន QR (Setup Link) ដោយកាមេរ៉ា · 🖼️ QR ពីរូបភាព (រូបថតអេក្រង់ QR ដែលទទួលតាម chat) · ឬបិទភ្ជាប់ Link ក្នុងវាល Setup Link រួចចុច ប្រើ Link។
  3. វាយ Security PIN — មិនទាន់មាន PIN ➜ App ឲ្យបង្កើត PIN ថ្មីមុន។
  4. ស្កេន QR ឬបិទភ្ជាប់ Link ត្រឹមត្រូវ ➜ App រក្សាទុក ហើយភ្ជាប់ Server ភ្លាម។ បើក Link ពីសារ ➜ ប្រអប់បង្ហាញ Server ដែលនឹងភ្ជាប់ ➜ ពិនិត្យ ហើយចុច ✅ ភ្ជាប់។
  5. រង់ចាំស្ថានភាពបង្ហាញថា «ភ្ជាប់ Server រួចរាល់»។

បញ្ចូល Config ដោយដៃ

ក្នុងប្រអប់ ⚙️ ភ្ជាប់ប្រព័ន្ធ បើក switch ✍️ បំពេញ Config ដោយដៃ ជ្រើសប្រភេទ Server ហើយចុច រក្សាទុក និងភ្ជាប់ ៖

  • Firebase ៖ ចម្លង object config ពី Firebase Console → Project settings → Your apps។ វាត្រូវមានវាលដូចជា apiKey, authDomain, databaseURL, projectId និង appId។
  • Supabase ៖ បំពេញ Project URL (https://….supabase.co) និង Publishable key (sb_publishable_…) ពី Supabase → Project Settings → API។ ⛔ App បដិសេធ Secret key (sb_secret_…)។
សុវត្ថិភាព៖ Firebase Config មិនមែនជាពាក្យសម្ងាត់ ប៉ុន្តែ Database Rules និង Authentication ត្រូវតែកំណត់ត្រឹមត្រូវ។ កុំផ្ញើ PIN, ពាក្យសម្ងាត់ ឬ API secret ក្នុង chat ឬ screenshot។

៣ខ. គណនីហាង ៖ ចុះឈ្មោះដោយកូដអញ្ជើញ

ហាងដែលអ្នកលក់បង្កើតក្នុង ប្រព័ន្ធរួម (Supabase) ចូលប្រើដោយ កូដអញ្ជើញ ៖ អ្នកចុះឈ្មោះដោយខ្លួនឯង ហើយគណនីចងនឹងហាង និងលេខសាខា ZTO របស់ហាងដោយស្វ័យប្រវត្តិ។

ម្ចាស់ហាងចុះឈ្មោះលើកដំបូង

  1. បើក Setup Link ឬស្កេន QR ដែលអ្នកលក់ផ្ញើ (Link ផ្ទុកកូដអញ្ជើញ)។
  2. វាយ Security PIN (មិនទាន់មាន ➜ បង្កើតថ្មី) ពិនិត្យ Server លើកាត Setup Link រួចចុច ✅ ភ្ជាប់ (ស្កេន QR ក្នុងប្រអប់ ⚙️ ភ្ជាប់ប្រព័ន្ធ ➜ ភ្ជាប់ភ្លាម)។ កាតបង្ហាញ ⚠️ ពេល Server មិននៅលើ domain ផ្លូវការរបស់ Supabase ឬ Firebase។
  3. App ពិនិត្យកូដអញ្ជើញជាមួយ Server ➜ កូដនៅប្រើបាន ➜ ប្រអប់ 📝 ចុះឈ្មោះ លេចដោយស្វ័យប្រវត្តិ (កូដបំពេញរួច)។ កូដប្រើរួច ឬផុត ➜ App បង្ហាញប្រអប់ ចូលប្រព័ន្ធ ជំនួស (ហាងនោះមានគណនីរួច)។
  4. ជ្រើស ឈ្មោះគណនី (៣–៣២ តួ ៖ a–z · 0–9 · . · _) និង ពាក្យសម្ងាត់ យ៉ាងតិច ៨ តួ (វាយ ២ ដង) ➜ ចុះឈ្មោះ ➜ App ចូលប្រព័ន្ធភ្លាម។
កូដអញ្ជើញប្រើបានតែ ១ ដង ហើយផុតកំណត់ក្នុង ៧ ថ្ងៃ។ កូដខុស ប្រើរួច ឬផុត ➜ សុំកូដថ្មីពីអ្នកលក់។
