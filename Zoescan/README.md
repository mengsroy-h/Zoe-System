# Zoescan - កំណត់ទីតាំង Locker

**Zoescan** គឺជាកម្មវិធីគេហទំព័រ (Web App) ដាច់ដោយឡែក សម្រាប់បុគ្គលិកប្រើប្រាស់ដើម្បី **កំណត់ទីតាំង Locker** ជូនកញ្ចប់ទំនិញ (Parcel/Package) ដែល **មានទិន្នន័យ Barcode ស្រាប់ក្នុង Firebase រួចហើយ** (បញ្ចូលដោយ ZoeAdmin)។ កម្មវិធីនេះមានតែមុខងារតែមួយគត់៖ ជ្រើសរើសទីតាំង Locker សិន រួចស្កេន Barcode ដើម្បីកត់ត្រាថាកញ្ចប់នោះស្ថិតនៅទីតាំងណា។

កម្មវិធីនេះជា **App កំណត់ទីតាំង Locker** ក្នុងប្រព័ន្ធតែមួយជាមួយ **ZoeAdmin** (App គ្រប់គ្រងសំខាន់ ដែលបញ្ចូលទិន្នន័យកញ្ចប់ថ្មី) និង **ZoeW** (App សម្រាប់ការទទួល/តាមដានកញ្ចប់)។ Zoescan **មិនបញ្ចូលកញ្ចប់ថ្មី និងមិនបង្កើត Barcode ថ្មីទេ** — វាស្កេនតែ Barcode ដែលមានស្រាប់ ដើម្បីធ្វើបច្ចុប្បន្នភាពទីតាំង Locker ប៉ុណ្ណោះ។ គណនី `admin`, `worker`, ឬ `scanner` ទាំងអស់អាចប្រើ Zoescan បាន (ដើម្បីអោយ Admin/Worker ក៏អាចជួយកំណត់ទីតាំង Locker បានផងដែរ)។

Zoescan **មិនអានទិន្នន័យពេញលេញរបស់កញ្ចប់ទេ** — វាអានតែពី node ដាច់ដោយឡែក `zoew_scanner_lookup` ដែលមានតែ **លេខទូរស័ព្ទ + Barcode + Locker** (គ្មាន COD/DOD ឬស្ថានភាពអាជីវកម្មផ្សេងទៀតទេ) ដើម្បីកំណត់សិទ្ធិអោយតឹងតែងតាមមុខងារពិតប្រាកដដែល Zoescan ត្រូវការ។ ប្រសិនបើ Zoescan រកមិនឃើញកញ្ចប់ណាមួយ សូមប្រាប់ Admin ចុចប៊ូតុង "កំណត់ទិន្នន័យ Scanner Lookup ឡើងវិញ" ក្នុង ZoeAdmin។

កម្មវិធីនេះជា **PWA (Progressive Web App)** អាចដំឡើងលើទូរស័ព្ទ ឬកុំព្យូទ័របាន ហើយប្រើ **Firebase** (Authentication + Realtime Database) ជា Backend ដូចគ្នានឹង ZoeAdmin/ZoeW។ Service Worker ធ្វើបច្ចុប្បន្នភាពកូដស្វ័យប្រវត្តិនៅពេល Deploy ថ្មី (មិនចាំបាច់ដំឡើង PWA ថ្មីទេ) ហើយបង្ហាញសារបញ្ជាក់ខ្លីៗនៅពេលធ្វើបច្ចុប្បន្នភាពរួច។

## លក្ខណៈពិសេស (Features)

- 🔐 **ការចូលប្រើប្រាស់សុវត្ថិភាព** — ចូលប្រើប្រាស់តាមរយៈ Firebase Authentication (Email/Password) គណនីដូចគ្នានឹង ZoeAdmin/ZoeW, និងកូដ PIN សុវត្ថិភាពសម្រាប់ការកំណត់រចនាសម្ព័ន្ធ
- 🗄️ **ជ្រើសរើសទីតាំង Locker មុនស្កេន** — ជ្រើសរើសទូ/ទីតាំង (ឧ. ទូ1, ទូ2... ឬកំណត់ឈ្មោះផ្ទាល់ខ្លួន) មុននឹងអនុញ្ញាតឲ្យស្កេន Barcode បាន
- 📷 **ស្កេន Barcode** — ស្កេនតាមកាមេរ៉ា (Native `BarcodeDetector` ជាចម្បង, ZXing ជា Fallback — ដាច់ដោយឡែកពីគ្នា ដូច្នេះកាមេរ៉ានៅតែប្រើបានទោះ ZXing CDN load មិនចេញក៏ដោយ), ម៉ាស៊ីនស្កេន Bluetooth/USB, វាយបញ្ចូលដោយដៃ ឬស្កេនពីរូបភាព
- 🔎 **ផ្គូផ្គងជាមួយទិន្នន័យស្រាប់** — ស្កេនរួច ប្រព័ន្ធរកមើលកញ្ចប់ដែលមាន Barcode នេះស្រាប់ក្នុង `zoew_scanner_lookup` ហើយធ្វើបច្ចុប្បន្នភាពទីតាំង Locker ភ្លាមៗនៅទាំងពីកន្លែង (ទិន្នន័យសំខាន់ + Lookup) ក្នុងពេលតែមួយ (មិនអាចបញ្ចូលកញ្ចប់ថ្មីបានទេ ប្រសិនបើ Barcode មិនទាន់មានក្នុងប្រព័ន្ធ)
- 📋 **បញ្ជីមើលទិន្នន័យ** — មើលបញ្ជីកញ្ចប់ដែលបានកំណត់ទីតាំង Locker រួច ដោយបង្ហាញ **លេខរៀងបញ្ច្រាស** (ល.រ), **លេខទូរស័ព្ទ** និង **ទីតាំង Locker** ព្រមទាំងអាចត្រង/ស្វែងរកបាន
- 📱 **ដំឡើងជា App បាន (PWA)** — គាំទ្រ Service Worker សម្រាប់ប្រើប្រាស់ក្រៅបណ្តាញ (Offline) និងទទួលបានកូដថ្មីស្វ័យប្រវត្តិគ្រប់ពេល Deploy ដោយមិនចាំបាច់ដំឡើងសាថ្មីទេ

## សុវត្ថិភាព (Security)

- ការចូលប្រើប្រាស់តម្រូវឲ្យមានគណនី Firebase Authentication (គណនីដូចគ្នានឹង ZoeAdmin/ZoeW)
- មានកូដ PIN ដាច់ដោយឡែកសម្រាប់ការកែប្រែការកំណត់រចនាសម្ព័ន្ធ (Config) និងការកំណត់ចំនួន/ឈ្មោះទូ Locker
- ទិន្នន័យទាំងអស់ដែលមកពី Firebase (លេខទូរស័ព្ទ, Barcode, ទីតាំង) ត្រូវបាន Escape មុននឹងបង្ហាញ ដើម្បីការពារការវាយប្រហារ XSS
- Zoescan មិនអាចបញ្ចូល ឬលុបកញ្ចប់ថ្មីបានទេ — កែប្រែបានតែវាលទីតាំង Locker របស់ Barcode ដែលមានស្រាប់ប៉ុណ្ណោះ (Server-side rule `firebase-database.rules.json` រឹតបន្តឹងច្បាស់លាស់ថា Scanner សរសេរបានតែវាល Locker)
- **គណនី Scanner លែងអានឃើញ COD/DOD ឬលេខទូរស័ព្ទពេញលេញនៃកញ្ចប់ដទៃទៀតទេ** — Zoescan អានតែពី `zoew_scanner_lookup` ដែលមានតែ Phone + Barcode + Locker ដែលជាមុខងារពិតប្រាកដដែល Zoescan ប្រើ (មិនមែន COD/DOD ឬស្ថានភាពអាជីវកម្មទៀតទេ)
