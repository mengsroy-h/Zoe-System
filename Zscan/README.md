# Zscan - កំណត់ទីតាំង Locker

**Zscan** គឺជាកម្មវិធីគេហទំព័រ (Web App) ដាច់ដោយឡែក សម្រាប់បុគ្គលិកប្រើប្រាស់ដើម្បី **កំណត់ទីតាំង Locker** ជូនកញ្ចប់ទំនិញ (Parcel/Package) ដែល **មានទិន្នន័យ Barcode ស្រាប់ក្នុង Firebase រួចហើយ** (បញ្ចូលដោយ ZoeAdmin)។ កម្មវិធីនេះមានតែមុខងារតែមួយគត់៖ ជ្រើសរើសទីតាំង Locker សិន រួចស្កេន Barcode ដើម្បីកត់ត្រាថាកញ្ចប់នោះស្ថិតនៅទីតាំងណា។

កម្មវិធីនេះជា **App កំណត់ទីតាំង Locker** ក្នុងប្រព័ន្ធតែមួយជាមួយ **ZoeAdmin** (App គ្រប់គ្រងសំខាន់ ដែលបញ្ចូលទិន្នន័យកញ្ចប់ថ្មី) និង **ZoeW** (App សម្រាប់ការទទួល/តាមដានកញ្ចប់) ដោយអានទិន្នន័យរួមគ្នាតាមរយៈ Firebase Database ដូចគ្នា។ Zscan **មិនបញ្ចូលកញ្ចប់ថ្មី និងមិនបង្កើត Barcode ថ្មីទេ** — វាស្កេនតែ Barcode ដែលមានស្រាប់ ដើម្បីធ្វើបច្ចុប្បន្នភាពទីតាំង Locker ប៉ុណ្ណោះ។

កម្មវិធីនេះជា **PWA (Progressive Web App)** អាចដំឡើងលើទូរស័ព្ទ ឬកុំព្យូទ័របាន ហើយប្រើ **Firebase** (Authentication + Realtime Database) ជា Backend ដូចគ្នានឹង ZoeAdmin/ZoeW។

## លក្ខណៈពិសេស (Features)

- 🔐 **ការចូលប្រើប្រាស់សុវត្ថិភាព** — ចូលប្រើប្រាស់តាមរយៈ Firebase Authentication (Email/Password) គណនីដូចគ្នានឹង ZoeAdmin/ZoeW, កូដ PIN សុវត្ថិភាពសម្រាប់ការកំណត់រចនាសម្ព័ន្ធ, និងប្រព័ន្ធការពារការបើក Developer Tools
- 🗄️ **ជ្រើសរើសទីតាំង Locker មុនស្កេន** — ជ្រើសរើសទូ/ទីតាំង (ឧ. ទូ1, ទូ2... ឬកំណត់ឈ្មោះផ្ទាល់ខ្លួន) មុននឹងអនុញ្ញាតឲ្យស្កេន Barcode បាន
- 📷 **ស្កេន Barcode** — ស្កេនតាមកាមេរ៉ា (Camera, engine ដូចគ្នានឹង ZoeAdmin), ម៉ាស៊ីនស្កេន Bluetooth/USB, វាយបញ្ចូលដោយដៃ ឬស្កេនពីរូបភាព
- 🔎 **ផ្គូផ្គងជាមួយទិន្នន័យស្រាប់** — ស្កេនរួច ប្រព័ន្ធរកមើលកញ្ចប់ដែលមាន Barcode នេះស្រាប់ក្នុង Firebase ហើយធ្វើបច្ចុប្បន្នភាពទីតាំង Locker ភ្លាមៗ (មិនអាចបញ្ចូលកញ្ចប់ថ្មីបានទេ ប្រសិនបើ Barcode មិនទាន់មានក្នុងប្រព័ន្ធ)
- 📋 **បញ្ជីមើលទិន្នន័យ** — មើលបញ្ជីកញ្ចប់ដែលបានកំណត់ទីតាំង Locker រួច ដោយបង្ហាញ **លេខរៀងបញ្ច្រាស** (ល.រ), **លេខទូរស័ព្ទ** និង **ទីតាំង Locker** ព្រមទាំងអាចត្រង/ស្វែងរកបាន
- 📱 **ដំឡើងជា App បាន (PWA)** — គាំទ្រ Service Worker សម្រាប់ប្រើប្រាស់ក្រៅបណ្តាញ (Offline)

## សុវត្ថិភាព (Security)

- ការចូលប្រើប្រាស់តម្រូវឲ្យមានគណនី Firebase Authentication (គណនីដូចគ្នានឹង ZoeAdmin/ZoeW)
- មានកូដ PIN ដាច់ដោយឡែកសម្រាប់ការកែប្រែការកំណត់រចនាសម្ព័ន្ធ (Config) និងការកំណត់ចំនួន/ឈ្មោះទូ Locker
- មានប្រព័ន្ធការពារការបើក Developer Tools ដើម្បីការពារទិន្នន័យ
- ទិន្នន័យទាំងអស់ដែលមកពី Firebase (លេខទូរស័ព្ទ, Barcode, ទីតាំង) ត្រូវបាន Escape មុននឹងបង្ហាញ ដើម្បីការពារការវាយប្រហារ XSS
- Zscan មិនអាចបញ្ចូល ឬលុបកញ្ចប់ថ្មីបានទេ — កែប្រែបានតែវាលទីតាំង Locker របស់ Barcode ដែលមានស្រាប់ប៉ុណ្ណោះ
