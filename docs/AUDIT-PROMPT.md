## ជំហាន ០ — baseline ពិត (SKIP ០) · ⛔ **រត់ក្នុង session នេះ មិនមែន GitHub**

```bash
npm i acorn playwright-core xlsx firebase-tools
npx --no-install firebase setup:emulators:database
setsid nohup java -jar ~/.cache/firebase/emulators/firebase-database-emulator-*.jar \
    --port 9000 --host 127.0.0.1 > /tmp/emu.log 2>&1 < /dev/null &
cp firebase-database.rules.json audit-tools/emu/real.rules.json
CRUD_FLOW_STRICT=1 VERSIONSCOPE_STRICT=1 bash audit-tools/run-all.sh
MONEYGUARD_STRICT=1 node audit-tools/money-guardian-test.js
```

⛔ **`SKIP` មិនមែន `PASS` ទេ** — មាន SKIP សូម្បី ១ កុំអះអាងថា tree បៃតង។
⛔ រាយ **ចំនួន PASS ពិត** ជាលេខ។ ជុំមុនបាន **១៦៦ PASS · 0 SKIP · 0 FAIL**។
⚠️ កុំបិទ emulator ដោយ `pkill -f firebase-database-emulator` (វាសម្លាប់ session)។
⚠️ `run-all.sh` ចំណាយ **~៤០ នាទី** ➜ រត់វាជា background រួចធ្វើការស្រាវជ្រាវ
ស្របគ្នា; ⛔ កុំរត់ checker browser ស្របគ្នានឹងវា (ប្រណាំងធនធាន)។

## ជំហាន ២ — បច្ចេកទេសដែលរកឃើញកំហុសពិត (មិនមែនការអានកូដ)

### ក. តារាងប្រៀបធៀបផ្នែកបងប្អូន
ដាក់ផ្នែក ២ ដែលមាន **រូបរាងដដែល** ក្បែរគ្នា រួចសួរជួរនីមួយៗ។

### ខ. `grep` កន្លែងហៅ **ទាំងអស់** របស់ធនធានចែករំលែក
ពិនិត្យ **ម្តងមួយ** ៖ សរសេរតាម delta របស់ **សតិ** ឬតាម **សាលក្រម server**?

### គ. ដាក់ dependency ក្នុងរបៀបបរាជ័យទាំង ៤
បដិសេធ · **អវត្តមាន** (`TypeError` synchronous) · **ព្យួរ** · **យឺតតែជោគជ័យ** —
មើលតារាងក្នុង `CLAUDE.md` ផ្នែក «ការព្យួរ ≠ ការធ្លាក់»។ អនុវត្តលើ **ការដកវិញ**
ដែរ (`ledger-failed-apply-revert-test` · `emu/ledger-revert-emu-test`)។
⛔ **RTDB មិនបដិសេធពេលក្រៅបណ្តាញទេ — វា *ចាក់ជួរ*** ➜ អ្នកកេះពិតជា
`permission_denied` និង `maxretry`។

### ឃ. **កម្រិតបូក (aggregation level)** — មានអ្នកយាមរួច
`Σ_d f(x_d)` ≠ `f(Σ x_d)` ពេល `f` មិនលីនេអ៊ែរ (`Math.max` · `clamp` · `round`)។
ស្កេន ៖ រកគ្រប់ការបូកលើសំណុំ រួចសួរ «clamp នៅ **ខាងក្នុង** ឬ **ខាងក្រៅ**?»។
អ្នកយាម ៖ `stats-screen-agreement-test`។

### ង. **សិទ្ធិវាស់ (measurability)** — មានអ្នកយាមរួច
**រាប់ប្រភពរបស់រូបមន្ត រួចរាប់ប្រភពដែលច្រកទ្វារពិនិត្យ — ២ លេខនេះត្រូវស្មើគ្នា។**
ការដកកុហក **២ ខាង** ➜ ការសរសេរច្បាប់តែទិសមួយ **ធានាថាទិសទី ២ គ្មានអ្នកយាម**។
⛔ ច្បាប់នេះគ្របសាខា **«គ្មានទិន្នន័យ»** ដែរ។
អ្នកយាម ៖ `stats-measurable-gate-test` · `empty-state-truth-test`។

### ច. **ការបោសសំអាតតាមផ្ទៃ** — មានអ្នកយាមរួច
បន្ទាប់ពីបិទថ្នាក់មួយ សួរ «ផ្ទៃ *ណាទៀត*?» ➜ រាយ **គ្រប់ផ្ទៃ** នៃតំបន់នោះ
រួចសួរក្នុងមួយផ្ទៃ ៖ «**មានតេស្តលំដាប់ចៃដន្យទេ?**»។ ⛔ បន្ទាប់មក
**mutate ជំនួសការសាង** — សម្មតិកម្មអំពីចន្លោះត្រូវវាស់មុន។
អ្នកយាមផ្ទៃលុយ ៖ `revenue-fuzz-test` (ledger) · `collected-value-fuzz-test` (បង្ហាញ)។
