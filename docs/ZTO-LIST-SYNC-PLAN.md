## ២. API ៖ អ្វីដែលវាស់រួច

### ២.១ សំណើបញ្ជី (អ្វីដែលយើងត្រូវការ)

```
POST https://aargus-api.ztoglobal.com/scan/page/scan
```

```json
{
  "condition": {
    "dispatchOrSendManCode": null,
    "mailNos": [],
    "preOrNextStationCode": null,
    "scanEndTime": "2026-09-11 23:59:59",
    "scanManCode": null,
    "scanSiteCode": "881859",
    "scanStartTime": "2026-09-08 00:00:00",
    "scanTypeCode": "03",
    "signMan": null
  },
  "pageNum": 1,
  "pageSize": 100
}
```

| វាល | អត្ថន័យ |
|---|---|
| `scanTypeCode: "03"` | **«អីវ៉ាន់មកដល់»** (Arrival Scan) — ⛔ នេះជាតម្រងស្នូល |
| `scanSiteCode: "881859"` | សាខារបស់អ្នកប្រើ (`Mer SorChrey`) |
| `mailNos: []` | ទទេ = ទាញតាមជួរកាលបរិច្ឆេទ; បើដាក់លេខចូល = សួរតែលេខទាំងនោះ |
| `pageSize` | អតិបរមាដែលវាស់ ៖ ១០០ |

### ២.២ សំបកចម្លើយ

```json
{ "data": { "pageNum": 1, "pages": 2, "total": 115, "result": [ … ] },
  "error": null, "success": true }
```

⛔ `upstreamSucceeded()` ដែលមានស្រាប់ **ទទួលយកសំបកនេះបាន** (`success === true`)។
⛔ តែ `orderCandidates()` ដែលមានស្រាប់ **រកមិនឃើញ** ជួរដេកទេ — វារកវត្ថុ
**តែមួយ** ខណៈបញ្ជីនៅក្នុង `data.result[]` ជា **array** ➜ ត្រូវការអ្នកស្រង់ថ្មី។

### ២.៣ ការផ្គូផ្គងវាល (វាស់លើជួរដេកពិត ១៧៤)

| ZoeW | វាល ZTO | ស្ថានភាព |
|---|---|---|
| `barcode` | **`scanBillCode`** | ⛔ **មិនមាន** ក្នុង `BARCODE_PATHS` ➜ ត្រូវបន្ថែម |
| `phone` | `consigneeMobile` | ✅ មានរួចជាបេក្ខជនទី ២ ក្នុង `PHONE_PATHS` |
| `cod` | `agentAmount` | ✅ បេក្ខជនទី ១ ក្នុង `COD_PATHS` |
| **`dod`** | **គ្មាន** | ⛔ បញ្ជី **មិនផ្ទុក DOD សោះ** |
| ម៉ោង | `scanTime` (`"2026-09-10 14:14:02"`) | ត្រូវបម្លែងទៅទម្រង់ ZoeW |

⛔ `fcAmount` = **ថ្លៃដឹក** មិនមែន DOD — ⛔ **កុំយកវាធ្វើជា DOD**។

### ២.៤ Endpoint ដែល **មិន** ត្រូវការ

`POST /scan/page/scan/getCodBillCount` ➜ ត្រឡប់ **សង្ខេបសរុប** ប៉ុណ្ណោះ
(`agentAmount: 399.88` · `fcAmount: 36.00` · `allNeedPay: 435.88` · ទម្ងន់)។
COD ក្នុងមួយកញ្ចប់មានក្នុងបញ្ជីរួចហើយ។ ⚠️ វាមានតម្លៃតែជា **ការផ្ទៀងផ្ទាត់
ឆ្លង** (ផលបូករបស់យើង ធៀបលេខផ្លូវការរបស់ Argus) — មិនមែនដំណាក់ ១ ទេ។
