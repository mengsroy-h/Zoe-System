Firebase** · និង **មិនផ្ញើទិន្នន័យទៅណាទាំងអស់**។ វាគ្រាន់តែអានឯកសារដែលអ្នក
ទាញចុះ រួចប្រាប់ថាលេខលុយក្នុងប្រព័ន្ធស៊ីគ្នាឬអត់។

## កំណែ

ជាឧបករណ៍វិនិច្ឆ័យ — **គ្មានកំណែផ្ទាល់ខ្លួន** ហើយ **មិនប៉ះកំណែ App** ទេ។

## មុខងារ

វាយកកូដលុយ **ពិត** ចេញពី `ZoeW/app.js` មករត់លើទិន្នន័យរបស់អ្នក រួចពិនិត្យ ៦ ៖

| # | ការវាស់ | បើខុស អ្នកនឹងឃើញអ្វី |
|---|---|---|
| ១ | ledger **ខែ** = ផលបូក ledger **ថ្ងៃ** | ស្ថិតិ ៣ ខែ ខុសពីរបាយការណ៍ខែ |
| ២ | លុយសរុប**ជួរដេក** = ផលបូក barcodes | លេខខុសក្នុង Excel និងលើអេក្រង់ |
| ៣ | ស្ថិតិយក ៖ សំណុំ barcode = `packagesPickedUp` = Σ `pickedUpPhones` | ចំនួន «យករួច» ខុស |
| ៤ | លេខអវិជ្ជមាន ឬ NaN ក្នុង ledger | ចំណូលបង្ហាញចម្លែក |
| ៥ | **«ចំណូល (យករួច)»** ក្នុងមួយខែ + ការអភិរក្ស | លេខចំណូលមិនត្រូវ |
| ៦ | barcode ស្ទួន | ហានិភ័យលុយបូកស្ទួន |

## របៀបប្រើប្រាស់

**ជំហាន ១ — ទាញទិន្នន័យចុះ**

1. បើក [Firebase Console](https://console.firebase.google.com) ➜ ជ្រើស Project របស់អ្នក
2. ម៉ឺនុយឆ្វេង ➜ **Realtime Database**
3. ចុចរូប **⋮** (ចំណុច ៣) នៅខាងស្តាំលើតារាងទិន្នន័យ ➜ **Export JSON**
4. ឯកសារ `.json` នឹងធ្លាក់ចូល **Downloads**

> 🔴 **សំខាន់ ៖ ថតនេះត្រូវនៅ *ក្នុងគម្រោង Zoe-System*។**
> ឧបករណ៍ត្រូវអាន `ZoeW/app.js` ដើម្បីយក **កូដលុយពិត** — ដូច្នេះវាឈរឯកឯងមិនបានទេ។
> បើអ្នកចម្លងតែថតនេះចេញទៅកន្លែងផ្សេង (ឧ. `D:\money-check-windows`)
> វានឹង **សួររកថតគម្រោង** ម្តង រួច **ចងចាំទុក** សម្រាប់លើកក្រោយ។
> បើអ្នកមិនទាន់មានគម្រោង ➜ GitHub ➜ ប៊ូតុង **Code** ➜ **Download ZIP** ➜ ពន្លា
> (ឧ. `D:\Zoe-System`)។

**ជំហាន ២ — រត់ឧបករណ៍**

1. ចុច ២ ដងលើ **`check-money.cmd`**
2. វានឹងសុំ `Dump file:` ➜ **អូសឯកសារ `.json` ពី Downloads មកទម្លាក់ក្នុងផ្ទាំងខ្មៅ** រួចចុច **Enter**
   *(ឬ ៖ អូសឯកសារ `.json` ទម្លាក់ដោយផ្ទាល់លើ `check-money.cmd` — វារត់ភ្លាម)*
3. របាយការណ៍**ជាភាសាខ្មែរ** នឹងបើកក្នុង **Notepad** ហើយរក្សាទុកលើ **Desktop**
   ជា `zoe-money-report.txt`

**ជំហាន ៣ — បើចង់ឲ្យខ្ញុំ (Claude) មើលជាមួយ**

ឧបករណ៍សាងឯកសារ **២** លើ Desktop ដោយស្វ័យប្រវត្តិ ៖

| ឯកសារ | ផ្ញើបានទេ? | ខ្លឹមសារ |
|---|---|---|
| `zoe-money-report.txt` | ✅ **បាន** | របាយការណ៍ខ្មែរ — មានតែថ្ងៃ · ចំនួន · ទឹកប្រាក់សរុប |
| `zoe-dump-SAFE-TO-SHARE.json` | ✅ **បាន** | ទិន្នន័យពេញ តែលេខទូរស័ព្ទ និង barcode ជំនួសដោយ hash |
| ឯកសារដើមពី Firebase | 🔴 **កុំផ្ញើ** | មានលេខទូរស័ព្ទ និងលុយអតិថិជន **ពិត** |

⛔ **ភស្តុតាងថាការសម្អាតមិនលាក់កំហុស** (វាស់បាន) ៖ ដាក់កំហុស ៥ ចូល dump រួច
សម្អាត ➜ **ចាប់បានទាំង ៥ ដដែល**។ ហើយលទ្ធផលមុន/ក្រោយសម្អាត **ដូចគ្នាបេះបិទ**។
⛔ hash ប្រើ salt **ចៃដន្យរាល់ការរត់** ➜ **បញ្ច្រាសមិនបាន** ទោះដឹងលេខទូរស័ព្ទក៏ដោយ។

**លទ្ធផលដែលអ្នកនឹងឃើញលើផ្ទាំងខ្មៅ** (ជាអង់គ្លេស ដោយចេតនា — `cmd.exe`
បំបែកអក្សរខ្មែរ) ៖

```
  passed  : 9
  warnings: 0
  FAILED  : 0
  RESULT  : all measured checks agree.
```

- **`FAILED : 0`** ➜ លុយក្នុងប្រព័ន្ធស៊ីគ្នាគ្រប់អ័ក្សដែលវាស់បាន
- **`FAILED` ធំជាង 0** ➜ បើករបាយការណ៍ ➜ វានឹងប្រាប់ **ថ្ងៃ/ខែណា និងគម្លាតប៉ុន្មាន**
- **`warnings`** មិនមែនកំហុសទេ — វាជាចំណុចដែល «វាស់មិនបាន» ឬគម្លាតដែលអាចធម្មតា

⛔ **បើឃើញ `ERROR: the check could not run`** ➜ នោះជាបញ្ហា **ឧបករណ៍**
មិនមែនបញ្ហា **លុយ** ទេ។ គ្មានអ្វីត្រូវបានវាស់សោះ — កុំសន្និដ្ឋានថាលុយត្រឹមត្រូវ។

បើការលាក់ទិន្នន័យបរាជ័យ ឬគ្មានឯកសារលទ្ធផលថ្មី ឧបករណ៍បញ្ឈប់ដោយ exit `3`
ហើយមិនបង្ហាញ `SAFE TO SEND` ទេ។ របាយការណ៍លុយដែលបានសាងរួចនៅលើ Desktop
អាចអានបានដដែល; កុំផ្ញើ dump ដើម ឬច្បាប់ចម្លងដែលមិនទាន់ផ្ទៀងផ្ទាត់។

⚠️ **បើគ្មាន Node.js** ៖ ឧបករណ៍នឹងប្រាប់អ្នក ➜ ទាញកំណែ **LTS** ពី
[nodejs.org](https://nodejs.org) ➜ តំឡើង ➜ បិទផ្ទាំងខ្មៅ ➜ ចុច ២ ដងម្តងទៀត។
