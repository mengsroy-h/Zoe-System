# 📥 ZTO Excel ➜ ZoeAdmin Sheet — ឧបករណ៍នាំចូលស្វ័យប្រវត្តិ

ឧបករណ៍នេះជំនួសការ **copy-paste ដោយដៃ** ពី Excel ដែល export ចេញពី website ZTO
ចូលទៅ Google Sheet `Customers` (ដែលដើរតួជា Lookup API របស់ ZoeW)។

> **វាជាគម្រោង Apps Script ដាច់ដោយឡែកទាំងស្រុង។** វា **មិនប៉ះ** ZoeW,
> មិនប៉ះ `ZoeW/google-sheets-api/Code.gs` (Lookup API ដែលកំពុងដើរ) និងមិនប៉ះ
> Firebase ឡើយ។ វាគ្រាន់តែសរសេរជួរដេកចូល Sheet ដដែលដែលអ្នកបញ្ចូលដោយដៃសព្វថ្ងៃ។

## មានផ្លូវប្រើ ២ — ជ្រើសយកមួយ ឬយកទាំង ២

| ផ្លូវ | របៀបប្រើ | ល្អត្រង់ណា |
|---|---|---|
| **ក. ទំព័រ Web** | បើក URL ➜ ទម្លាក់ file ➜ ចុច «នាំចូល» ➜ ឃើញលទ្ធផលភ្លាម | ដើរគ្រប់ឧបករណ៍ រួមទាំងទូរស័ព្ទ; ឃើញ preview មុននាំចូល |
| **ខ. Folder ស្វ័យប្រវត្តិ** | ទម្លាក់ file ចូល folder `ZTO-Inbox` ក្នុង Drive ➜ **រួច** | គ្មានប៊ូតុងត្រូវចុចសោះ; file ផ្លាស់ទៅ `ZTO-Done` ដោយខ្លួនឯង |

ផ្លូវ **ខ** ត្រូវការឲ្យផ្លូវ **ក** ដំណើរការម្តងជាមុនសិន (ដើម្បីចងចាំការផ្គូផ្គង
Column របស់ file ZTO) — លើកក្រោយវាចាំបាន ហើយធ្វើដោយខ្លួនឯងរហូត។

## ជំហានទី ១ — បង្កើតគម្រោង Apps Script

1. បើក <https://script.google.com> ➜ **New project**
2. ប្តូរឈ្មោះគម្រោងជា `ZTO Import`
3. បង្កើតឯកសារតាមតារាងនេះ ហើយ **ចម្លងខ្លឹមសារពី folder នេះដាក់ជំនួសទាំងស្រុង**៖

| ឯកសារក្នុង Apps Script | ប្រភេទ | ចម្លងពី |
|---|---|---|
| `Code.gs` | Script | `Code.gs` |
| `Watch.gs` | Script | `Watch.gs` — *(ត្រូវការតែពេលប្រើផ្លូវ **ខ**)* |
| `Index.html` | HTML | `Index.html` |

> បង្កើតឯកសារថ្មី៖ ចុច **➕** ក្បែរ «Files» ➜ ជ្រើស **Script** ឬ **HTML**។
> ឈ្មោះត្រូវដូចបេះបិទ (គ្មាន `.gs` / `.html` ពេលវាយឈ្មោះ)។

## ជំហានទី ២ — កំណត់ Script Properties

⚙️ **Project Settings** ➜ រមូរចុះទៅ **Script Properties** ➜ **Add script property**៖

| Property | ចាំបាច់? | តម្លៃត្រូវដាក់ |
|---|---|---|
| `SHEET_ID` | ✅ ចាំបាច់ | លេខសម្គាល់ Sheet — យកពី URL៖ `https://docs.google.com/spreadsheets/d/`**`<នេះជា SHEET_ID>`**`/edit` |
| `IMPORT_PASSWORD` | ✅ ចាំបាច់ | ពាក្យសម្ងាត់ដែលអ្នកបង្កើតខ្លួនឯង (វែងៗ ចៃដន្យ) សម្រាប់បើកទំព័រ Web |
| `SHEET_NAME` | ជម្រើស | ឈ្មោះ tab គោលដៅ — លំនាំដើម `Customers` |
| `NOTIFY_EMAIL` | ជម្រើស | អ៊ីមែលដែលចង់ទទួលសេចក្តីសង្ខេប ពេលផ្លូវ **ខ** នាំចូលចប់ |

> ⚠️ បើ `IMPORT_PASSWORD` មិនបានកំណត់ ឧបករណ៍ **បដិសេធរាល់សំណើ** (fail closed)
> ដូច `Code.gs` របស់ Lookup API ដែរ — ការភ្លេចជំហាននេះក្លាយជាកំហុសដែលមើលឃើញភ្លាម
> មិនមែនជារន្ធស្ងាត់ដែលអនុញ្ញាតឲ្យអ្នកដទៃសរសេរចូល Sheet របស់អ្នកទេ។

## ជំហានទី ៣ — Deploy ជា Web App (ផ្លូវ ក)

1. **Deploy ➜ New deployment** ➜ ចុច ⚙️ ➜ ជ្រើស **Web app**
2. Execute as: **Me** · Who has access: **Anyone**
3. **Deploy** ➜ **Authorize access** ➜ ជ្រើសគណនី ➜ Advanced ➜ Go to … ➜ **Allow**
4. ចម្លង **Web app URL** (បញ្ចប់ដោយ `/exec`) ទុក — នេះជា App នាំចូលរបស់អ្នក

> «Anyone» មានន័យថាអ្នកណាដឹង URL ក៏បើកទំព័របាន ដូច្នេះ **`IMPORT_PASSWORD`
> ជាការការពារពិត** — កុំចែក URL បូកពាក្យសម្ងាត់ជាមួយគ្នាតាមសារសាធារណៈ។

### របៀបប្រើ

1. បើក URL ➜ វាយពាក្យសម្ងាត់ ➜ **ដោះសោ** (browser ចាំទុកលើកក្រោយ)
2. ទម្លាក់ file Excel របស់ ZTO ➜ ឧបករណ៍អាន Column ដោយស្វ័យប្រវត្តិ
3. ពិនិត្យតារាង preview (៨ ជួរដេកដំបូង) និងចំនួនដែលបង្ហាញ
4. ចុច **នាំចូលទៅ Sheet**

**លើកដំបូង** បើវារក Column មិនឃើញ សូមជ្រើសដោយដៃ (`A · Barcode`, `B · DOD($)`,
`C · COD($)`, `D · Phone`)។ ឧបករណ៍ **ចងចាំការជ្រើសនោះ** តាមទម្រង់ header របស់
file — លើកក្រោយ file ZTO បែបដដែលនឹងផ្គូផ្គងស្វ័យប្រវត្តិ។

### របៀបនាំចូល ៣

| របៀប | ធ្វើអ្វី | ប្រើពេលណា |
|---|---|---|
| **បន្ថែមថ្មី + កែអ្វីដែលប្រែ** *(លំនាំដើម)* | Barcode ថ្មី ➜ បន្ថែម; Barcode មានស្រាប់ ➜ កែតែពេល COD/DOD/Phone ប្រែ | ប្រើប្រចាំថ្ងៃ |
| **បន្ថែមតែ Barcode ថ្មី** | មិនប៉ះជួរដេកចាស់ណាមួយឡើយ | ពេលបានកែតម្លៃខ្លះក្នុង Sheet ដោយដៃ ហើយមិនចង់ឲ្យ file សរសេរជាន់ |
| **លុបទាំងអស់ រួចដាក់ថ្មីជំនួស** | លុបជួរដេកទាំងអស់ (លើកលែង header) រួចដាក់តែអ្វីក្នុង file | ពេលចង់ឲ្យ Sheet ស្មើនឹង file ថ្ងៃនេះបេះបិទ |

ជួរដេកដែល **គ្មាន Barcode ត្រូវរំលង**។ Barcode ស្ទួនក្នុង file ដដែល ➜ យក **ជួរចុងក្រោយ**។
ការប្រៀបធៀប Barcode **មិនប្រកាន់តួអក្សរធំតូច**។

## ជំហានទី ៤ (ជម្រើស) — Folder ស្វ័យប្រវត្តិ (ផ្លូវ ខ)

1. ក្នុង Apps Script ➜ **Services** (➕ ខាងឆ្វេង) ➜ បន្ថែម **Drive API** ➜ Add
   *(ចាំបាច់ ព្រោះការបំលែង `.xlsx` ➜ Google Sheet ត្រូវការវា)*
2. ជ្រើស function **`setupInboxWatch`** ពីបញ្ជីខាងលើ ➜ ចុច **Run** ➜ Authorize
3. មើល **Execution log** — វានឹងបង្ហាញតំណ folder `ZTO-Inbox`

រួចរាល់។ ចាប់ពីពេលនេះ៖

- ទម្លាក់ file Excel ចូល **`ZTO-Inbox`** (ពី PC អូសចូល Drive; ពីទូរស័ព្ទ
  ➜ Share ➜ Save to Drive)
- រៀងរាល់ **៥ នាទី** វាបញ្ចូលទៅ Sheet ដោយខ្លួនឯង
- ជោគជ័យ ➜ file ផ្លាស់ទៅ **`ZTO-Done`** · បរាជ័យ ➜ ផ្លាស់ទៅ **`ZTO-Failed`**
- បើកំណត់ `NOTIFY_EMAIL` ➜ ទទួលអ៊ីមែលសង្ខេប

ចង់បិទវិញ៖ រត់ function **`removeInboxWatch`**។

## អ្វីដែលត្រូវដឹង

- **ZoeW អាចយឺតរហូតដល់ ៥ នាទី** ទើបឃើញទិន្នន័យថ្មី — មិនមែនកំហុសរបស់ឧបករណ៍នេះទេ។
  Lookup API (`ZoeW/google-sheets-api/Code.gs`) មាន cache `CACHE_TTL_SECONDS = 300`។
  ចង់ឲ្យលឿនជាងនេះ ➜ បន្ថយតម្លៃនោះ (ឧ. `60`) នៅក្នុង script *នោះ* រួច Deploy វាឡើងវិញ។
- ឧបករណ៍នេះ **មិនកែទម្រង់លេខទូរស័ព្ទ ឬ Barcode ទេ** — វាដាក់តម្លៃចូលដូចអ្នក
  paste ដោយដៃបេះបិទ។ តែវា **កំណត់ format ជា Text** សម្រាប់ column Barcode និង
  Phone នៃជួរដេកដែលវាសរសេរ ដើម្បីកុំឲ្យលេខ ១៤ ខ្ទង់ក្លាយជា `7.713E+13`។
- ទឹកប្រាក់ត្រូវបង្គត់ ២ ខ្ទង់ (`Math.round(x * 100) / 100`) ដូច ZoeW ដែរ។
- កម្រិតមួយដង៖ **២០,០០០ ជួរដេក**។ ធំជាងនេះ សូមបំបែក file។
- ការនាំចូល ២ ដំណើរការមិនអាចជាន់គ្នាបានទេ (`LockService`)។
